# Tetra Software

**Software that keeps your data where it belongs — with you.**

Most software asks you to hand your data to someone else's cloud and trust it'll be fine. We took the other path. Everything we build is designed to run on *your* infrastructure — a digital workplace, applied AI, and security that are sovereign by default, with no vendor lock-in and nothing leaving the country unless you decide so.

### What we believe

- **Your data is yours.** On-premise first — you hold the keys, the storage, and the audit trail.
- **No lock-in.** Self-hostable, exportable, built on open standards. Stay because it works, not because you're trapped.
- **AI without the leak.** Models run on your own hardware — intelligence that never ships your documents to a stranger.

### What we do

- **Digital transformation** — a unified digital workplace (eOffice): official-dispatch handling (Decree 30), document management, drag-and-drop approval workflows, HR, and Vietnam-standard digital signing.
- **Cybersecurity** — self-hostable web/app protection, network security, and monitoring built for on-premise deployment.
- **Applied AI** — private, local AI for document digitization and internal knowledge.
